# PR 描述模板

> 程序员创建 PR 时必须按此格式填写描述。项目经理据此执行合并决策。

```yaml
pr_number: "#XXX"
issue_ref: "ISSUE-XXX"          # 关联 Issue
author: ""                      # 程序员
branch: "feat/ISSUE-XXX-desc"   # 分支名
created_at: "YYYY-MM-DD"
```

---

## 关联 Issue

Closes #ISSUE-XXX

> 如关联多个 Issue，逐一列出。

---

## 改动摘要

> 文件级粒度，列出主要改动。

- `src/xxx`：新增/修改了什么
- `src/yyy`：修改了什么
- `tests/zzz`：新增了什么测试

**变更统计**：+? 行 / -? 行，涉及 ? 个文件

---

## 验收标准覆盖

> 逐条回应 Issue 中的验收标准。

- [x] AC-1：{描述} — ✅ 已实现 / 说明
- [x] AC-2：{描述} — ✅ 已实现 / 说明
- [ ] AC-3：{描述} — ⚠️ 未实现，原因：_
